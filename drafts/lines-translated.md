## 翻訳上の判断と注意点

指定語彙は基本的に維持しました。特に注意してほしい箇所を挙げます。

| 箇所         | 判断                                                |
| ---------- | ------------------------------------------------- |
| 2「手足」      | 「手和脚」を採用。「手脚」も使えますが、別の慣用的意味もあるため、初学者には分解した形が明確です。 |
| 5「冷たい心」    | 「冰冷的心」を採用。所有の有と量詞「颗」の学習にも使えます。                    |
| 7「車」       | 「车」は自動車にもチェスのルークにも使えます。洒落として成立します。                |
| 9「顔が真っ青」   | 中国語では顔面蒼白を「脸都白了」と表現するのが自然なので、色を白に変更しました。          |
| 17「強い」     | 「你比我强！」とし、「私より強い」という比較構文にしました。                    |
| 17「母上・父上」  | 一般語としての再利用性から「妈妈・爸爸」を採用。王族らしさを優先するなら「母后・父王」も候補です。 |
| 18「チェスの本」  | 「棋书」で短く表現しました。対局の文脈ではチェスの本として理解できます。              |
| 20「〇〇が現れた」 | 「〇〇出现了！」としました。駒の種類に応じて置換できます。                     |
| 21「電話を貸して」 | 現代の日常会話として「借我手机！」を採用。「打电话」で電話することも表現しています。        |

「国破山河在」と「王侯将相，宁有种乎」は、希望どおり中国語の古典の原文を採用しました。ただし、どちらも文言文（古典中国語）なので、現代中国語の37 STEPの例文としては扱いません。

## 37 STEPの網羅性について

今回のセリフには、初級文法の典型例として使いやすいものがかなり含まれています。特に、是構文・形容詞述語文・了・進行の在・複合方向補語・様態補語は複数の例文から学べる構成です。

一方、次の項目は典型例が不足しています。

- STEP7：反復疑問文
- STEP11〜12：存在の有・所在の在
- STEP14：場所の指示代名詞
- STEP19：可能の助動詞
- STEP22：動作の時間
- STEP27：持続の着
- STEP29：単純方向補語
- STEP34〜36：存在文・現象文・把構文

これらについては、元のセリフの意味と自然さを保ったまま、典型例にするのが難しかったため、無理に文法を組み込みませんでした。

また、「我快哭了」の近接未来表現や「别生气啊」の禁止命令など、37 STEPに独立した項目が設けられていない文法も一部含まれています。いずれも現代中国語で自然に使われる表現です。
