# Chinese Learning Chess

チェスを指しながら、対戦キャラクターの中国語の台詞を学ぶNext.jsアプリです。

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) で開きます。

## 難易度

初回設定と設定画面のスライダーで、0〜100を0.1刻みで選べます。設定はブラウザーに保存され、次の対局から適用します。初期値は25です。

Stockfishの `UCI_LimitStrength` と `UCI_Elo` で強さを調整します。同梱のStockfish 19 Liteが対応する目標棋力1320〜3190に、スライダーを線形に対応させています。これはエンジンの目標設定であり、実際の対人レーティングを保証するものではありません。探索時間は全難易度で1手800msです。

左端の難易度0は入門向けに、AIの着手ごとに30%の確率でエンジンの選んだ手以外の合法手を均等に選び、ミスが出やすくしています。合法手が1つだけならその手を指します。0より大きい難易度ではエンジンの選んだ手をそのまま使います。この補正も次の対局から適用します。

旧設定は初級→0、中級→50、上級→90に移行します。対応関係は `app/difficulty.ts` で調整できます。

## 品詞分解

吹き出しのセリフを押すと、「セリフ本文を品詞分解」をGoogleのAIモード（`udm=50`）へ渡し、新しいタブで開きます。Googleは外部サイトへの埋め込みを許可していないため、ページ内表示は行いません。スピーカーボタンでは引き続き中国語を再生できます。

## 台詞の管理

台詞は既存90本と [追加原稿](drafts/chinese_chess_new_dialogues_182_2026-10-29.md) の182本を合わせた272本・33条件を使用します。既存90本の原文・訳は維持しています。「你有一颗冰冷的心！」の発動条件は、プレイヤーがAIのクイーンを取ったとき（条件10）に修正しています。旧4セットと設定画面のセット切り替えは廃止しました。以前のセット選択の保存値は参照しません。

- 既存の中国語と文法STEP: `drafts/lines-translated.md`
- 既存の日本語訳・単語と表現の解説: `scripts/generate-dialogues.mjs` の `groups`（原稿の条件・台詞順に対応）
- 追加の中国語・日本語訳・条件: `drafts/chinese_chess_new_dialogues_182_2026-10-29.md`
- 追加の学習解説・個別条件: `scripts/new-dialogues.mjs`（原稿の文法セクションに対応）
- アプリで使う生成データ: `app/data/lines-translated.json`、`app/data/lines-additional-2026-10-29.json`
- 発動判定: `app/dialogues.ts`

原稿を変更した場合は、日本語訳・解説も対応させ、次を実行します。生成データをアプリに直接組み込むため、旧セットのJSONへの通信は発生しません。

全272本のセリフには声調記号付きの拼音を保存し、吹き出しに拼音を大きく、その下に中国語を表示します。拼音は `scripts/dialogue-pinyin.mjs` と生成用の `pinyin-pro` で事前生成します。多音字・軽声・儿化の補正と「一」「不」の変調を反映し、第三声の連続変調は表記しません。読みを調整する場合は同スクリプトの辞書を更新して再生成してください。昇格時は中国語と拼音の両方を実際の駒名に置き換えます。

日本語訳は中国語の漢字の下に表示します。設定の「拼音を表示」「日本語訳を表示」でそれぞれ独立して切り替えられます。初期状態は両方オンで、拼音をオフにすると漢字が大きなメインの文字になります。変更は現在の吹き出しにもすぐ反映され、ブラウザーに保存して次回も引き継ぎます。

吹き出し内部はスクロールさせず、全文を表示します。セリフが1本なら吹き出し領域全体を使い、2本なら文章量に応じて高さを配分します。長いセリフでは領域を広げ、画面に収まらない場合は対局画面全体をスクロールできます。

```bash
npm run dialogues:generate
npm test
npm run lint
npm run build
```

`npm run dialogues:check` は原稿・解説・生成データの一致を確認します。テストにはTypeScriptを直接実行できるNode.js 22.18以降を使用してください。

## キャラクターの音声

自動読み上げとスピーカーボタンは、ブラウザーTTSの代わりに同梱のM4A音声を再生します。設定の「声」で、既存の「声1」と追加の「声2」を選べます。初期値は声1で、選択はブラウザーに保存して次回も引き継ぎます。選択中の対戦キャラクターに合わせて女性／男性の声を使い、「ランダム」ではその対局のキャラクターと声をそろえます。設定で声を切り替えると再生中の音声を停止し、次の再生から反映します。自動読み上げがオフでもスピーカーボタンでは再生できます。

音声は `public/voice/1/female/`・`public/voice/1/male/`（声1）、`public/voice/2/female/`・`public/voice/2/male/`（声2）に配置しています。追加音声は `downloads` から移動しました。各フォルダーの `audio-map.json` が台詞IDと `audio/*.m4a` を対応させ、`lines-index.json` に収録原文を保存しています。各272台詞・264ファイル（同じ中国語は共有）、計1,056ファイルです。昇格の「〇〇出现了！」も提供された共通の収録音声を使用します。駒名ごとに録り分けた音声ではありません。

再生終了後にAIの着手待ちを解除し、再生失敗やブラウザーの自動再生制限でも対局を続行できます。音声を追加・差し替えた際は対応表と収録原文も更新してください。`npm test` で全台詞の対応、原文の一致、音声ファイルの存在と形式を確認します。

## キャラクターの立ち絵

透過立ち絵は性別ごとにディレクトリを分け、すべて560×700pxのWebPでそろえています。

- `public/character/female/`: 女性キャラクターの10表情。通常・笑顔・自信・疑問・驚き・不安・動揺・怒り・悲しみ・得意顔を、それぞれ `neutral.webp`・`happy.webp`・`confident.webp`・`curious.webp`・`surprised.webp`・`worried.webp`・`distressed.webp`・`angry.webp`・`sad.webp`・`smug.webp` と命名しています。
- `public/character/male/neutral.webp`: 男性キャラクターの基本の立ち絵（現在は笑顔の1枚）。今後の表情差分も女性と同じファイル名で追加できます。

設定の「対戦キャラクター」で「女性」「男性」「ランダム」を選べます。初期値は女性で、変更はすぐ反映され、次回以降もブラウザーに保存します。「ランダム」を選ぶとその場で男女を等確率で選び、その後は新しい対局ごとに選び直します。対局中の着手やセリフの再生ではキャラクターを変えません。男性の未収録表情は基本画像を使います。画像を増やす場合は `app/character.ts` の `CHARACTER_PORTRAITS.male` に登録します。固有のキャラクター名は設定せず、画面読み上げ用のラベルでは「対戦キャラクター」と呼びます。

全272本の表情は `app/character.ts` の `DIALOGUE_EXPRESSIONS` で台詞IDごとに指定します。同じ発動条件でも、褒める台詞は笑顔、強がる台詞は自信のある顔など、内容に合わせて切り替えます。2本の吹き出しを表示するときは最新の台詞に対応し、スピーカーボタンで以前の台詞を再生するとその表情へ戻ります。台詞がないときは通常の表情です。新しい台詞を追加した際は表情も指定してください（未指定は通常の表情にフォールバックし、テストで指定漏れを検出します）。

画像は事前に軽量化済みのため再圧縮せず配信し、対局画面で全表情を読み込んで切り替え時の空白を防ぎます。

## 発動条件

条件番号は既存原稿の1〜31と追加原稿で新設した32〜33に対応します。

- 1〜10: AI／プレイヤーが種類別に駒を取った直後。アンパッサンもポーンの捕獲として扱います。
- 11: 相手が直前に取ったマスで、同じ価値の駒を取り返したとき。
- 12〜14: その色で初めての対局／通常の開始。白番・黒番に言及する台詞は実際の色と一致するものだけを選びます。
- 15〜18: チェック／チェックメイトによる勝敗。引き分けには勝敗の台詞を出しません。
- 19〜20: 昇格。`〇〇` は実際の昇格先に置換します。「王后回来了！」「她回来了！」は、プレイヤーのクイーンが0個の状態からクイーンへ昇格した場合に限ります。「她也是王后！」は、プレイヤーがクイーンを持つ状態でさらにクイーンへ昇格した場合だけ選びます。
- 21〜22: その手によって、片側の駒がキング1個だけになったとき。
- 23〜24: ブラウザーの現地時刻で朝は5:00〜11:59、夜は18:00〜翌4:59に対局開始。
- 25〜26: AI／プレイヤーのキャッスリング。
- 27: 現地日付で当日2回目以降の対局開始。開始回数はブラウザーに保存します。
- 28: プレイヤーのルークが1手で4マス以上移動。
- 29〜30: **一度3点以上のマテリアル劣勢になった側が、その後3点以上の優勢になった瞬間。** 途中で互角や1〜2点差を挟んでも劣勢の記録を保持します。到達時に1回発動し、再び3点以上の劣勢になれば再度発動可能です。新しい対局では履歴をリセットします。
- 31〜32: AI／プレイヤーが動かした駒で新しくフォーク（ポーン以外の敵駒2個以上への同時攻撃）、キングへのピン、キング越しのスキュアーを作ったとき。それぞれ別の条件で選びます。
- 33: 条件15・16のチェック時に、実際の攻撃駒の位置と一致する方向台詞を候補に加えます。発見チェックでは動いた駒ではなく、チェックを与えている駒を調べます。「前／後」はチェックされた側の進行方向（白は8段目へ、黒は1段目へ）を基準にします。「上／下・左／右」は白側から見た固定盤面座標（上が8段目、左がaファイル）を使い、盤面表示の回転には連動しません。「他在我旁边！」はAIキングへの隣接攻撃だけ、「下面也有敌人！」は下側に加えて別方向からも同時にチェックされている場合だけ選びます。

マテリアルはポーン1・ナイト3・ビショップ3・ルーク5・クイーン9点で計算します。

1回の開始・着手につき台詞は1本です。開始時は「初めての色 → 当日2回目以降 → 朝／夜 → 通常」の優先順です。着手後は「チェックメイト → 昇格 → キングだけへの変化 → 逆転 → 交換 → AI／プレイヤーの技 → チェック（方向台詞を含む） → キャッスリング → 捕獲 → ルークの長距離移動」の順で選びます。逆転の履歴は、ほかの台詞が優先される手でも更新します。同じ条件内では候補を一巡するまで重複を避けます。
